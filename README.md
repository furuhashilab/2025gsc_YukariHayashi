## Abstract
  駅は日常的に多くの人が利用する公共空間であり、その設備整備は利用者の快適性とアクセシビリティに直結する重要な課題である。本研究は、駅構内に設置された多機能トイレに着目し、路線ごとの設置数、配置パターン、設備機能の実態を調査・分析した。
対象路線として、JR中央線、JR横浜線、東急東横線、東京メトロ副都心線、横浜市営地下鉄グリーンラインを取り上げ、開業年および乗客数との関係を検証した。加えて、調査結果をOpenStreetMap（OSM）に反映し、日本の駅特有の利用条件を表現する新たなタグ案を検討した。
分析の結果、新しい路線ほど多機能トイレの整備水準が高い傾向は確認された一方で、乗客数と設置数の間には明確な相関は見られなかった。また、「多機能トイレ」という名称にもかかわらず、設備内容や配置には大きなばらつきが存在することが明らかになった。
## Introduction
  多機能トイレは、障害者、高齢者、子ども連れ、オストメイト利用者、性的マイノリティなど、多様な利用者のニーズに対応するための重要な公共設備である。しかし、日本の駅構内における多機能トイレは、設置数・配置・設備水準が駅や路線ごとに異なり、必ずしも一貫した基準で整備されているとは言えない。
本研究では、「古い鉄道ほど構造的制約が大きく、多機能トイレが少ない」という仮説を設定し、複数路線の比較調査を通じて検証を行った。また、単なる設置数の比較にとどまらず、駅構内での配置パターンや設備機能の違いに注目し、アクセシビリティの観点から課題を整理することを目的とした。さらに、OSMを活用したデータ公開とタグ設計を通じて、調査成果の社会的活用可能性を探った。
## Methods
[3年での研究結果のまとめ](https://github.com/furuhashilab/2024gsc_YukariHayashi)
### 調査対象路線
- JR中央線（快速）：東京駅〜高尾駅（24駅）
- JR横浜線：東神奈川駅〜八王子駅
- 東急東横線：渋谷駅〜横浜駅
- 東京メトロ副都心線：和光市駅〜渋谷駅（16駅）
- 横浜市営地下鉄グリーンライン：日吉駅〜中山駅（10駅）  ￼
### 調査方法
1. 各駅の改札内に設置された多機能トイレの個数を実地調査により確認
2. 構内案内図および多機能トイレ内部の設備・内装を写真記録
3. 多機能トイレの配置を以下の5類型に分類
- サンドイッチ型:多機能トイレが男子トイレと女子トイレの間に配置され、両者に挟まれる空間構成。
- 飛び地型:多機能トイレが男女トイレとは離れた場所に独立して設置されている空間構成。
- コバンザメ型:多機能トイレが男子トイレまたは女子トイレのに隣接して配置される空間構成。
- インナー型:多機能トイレが男女トイレ群の内部に組み込まれている空間構成。
- 融合型:上記いずれか一つに明確に分類できず、複数の配置特性が組み合わさった空間構成。
4. 路線ごとに「駅あたりの多機能トイレ数（総数÷駅数）」を算出
5. 乗降人員データ（JR東日本・東京メトロ等の公開統計）と比較し、相関を検討
6. 調査結果をOSMに登録し、既存タグの整理および新規タグ案を検討

## Results
### 1. 設置数と開業年の関係
各路線における駅あたりの多機能トイレ設置数を比較した結果、以下の傾向が確認された。
	•	東京メトロ副都心線（2008年6月14日開業）：約 1.88 個／駅
	•	横浜市営地下鉄グリーンライン（2008年3月30日開業）：約 2.0 個／駅
	•	JR中央線（1889年開業）：約 1.16 個／駅
	•	JR横浜線（1908年開業）：約 1.0 個／駅
	•	東急東横線（1926年開業）：約 1.57 個／駅
2008年に開業した副都心線およびグリーンラインでは、駅あたりの多機能トイレ設置数が他路線と比べて多く、新しい路線ほど整備水準が高い傾向が確認された。特にグリーンラインでは、全駅で複数の多機能トイレが確保されており、バリアフリー対応が初期設計段階から重視されていたことが示唆される。
この傾向は、2006年に施行されたバリアフリー法の影響と関連している可能性がある。副都心線およびグリーンラインはいずれも、同法施行後に開業しており、駅施設の設計段階において、法制度で求められるバリアフリー基準や理念が反映された結果、多機能トイレの設置水準が高くなったと考えられる。
一方で、JR横浜線やJR中央線のような開業年が古い路線においても、近年の改修によって一定数の多機能トイレが整備されている駅が確認された。このことから、多機能トイレの設置状況は、開業年や法施行の有無だけで一律に説明できるものではなく、改修のタイミング、駅ごとの優先度、構造的制約など、複数の要因が重なり合って形成されていることが示された。
### 2. 乗客数との関係
駅ごとの1日平均乗降人員と多機能トイレ設置数を比較した結果、いずれの路線においても明確な相関関係は確認されなかった。
利用者数が非常に多い主要駅であっても、多機能トイレが1室のみ、あるいは他駅と同水準にとどまるケースが見られた一方で、比較的利用者の少ない駅でも最低1室は確保されている例が多かった。
この結果から、多機能トイレの整備は「需要（乗客数）」に基づいて最適化されているというよりも、構造上の制約や改修可能性、予算配分といった要因に強く左右されている実態が示された。
### 3. 配置パターンの分布
全107事例の多機能トイレを対象に配置パターンを分類した結果、
- サンドイッチ型:/107
- コバンザメ型: 107
の2類型に大きく集中していた。一方で、
- 飛び地型
- インナー型
- 融合型
は少数にとどまった。
サンドイッチ型は男女トイレの間に配置されるため視認性が高く、案内もしやすいという利点がある。一方で、通路幅が狭い場合には動線が交錯し、混雑やプライバシー面で課題が生じやすい。
コバンザメ型は男女トイレに隣接する形で設置されるため見つけやすいが、エレベーターや改札からの距離によっては、車いす利用者にとって遠回りになる場合がある。
この結果は、多機能トイレの「配置」が単なる空間構成ではなく、アクセシビリティや利用体験に直結する重要な要素であることを示している。
### 4. 設備機能のばらつき
多機能トイレ内部の設備を比較したところ、設備の有無や仕様には、駅ごとに大きなばらつきが確認された。
同じ「多機能トイレ」という名称であっても、必要な設備がすべて揃っているとは限らず、利用者によっては「設置されていても使えない」状況が生じる可能性がある。この点は、多機能トイレが担う役割と、実際の整備内容との間にギャップが存在していることを示唆している。

## Discussion
  本研究により、多機能トイレの整備状況は「量・質・配置」のいずれにおいても標準化が不十分であり、開業年や改修履歴、構造条件、事業者の判断に強く依存していることが明らかになった。
特に、乗客数との非相関は、需要に基づく整備よりも「設置可能性」が優先されている現状を示唆している。また、配置パターンの違いは、視認性や動線、混雑、プライバシーといったアクセシビリティに直接影響を与える要因である。
さらに、OSMタグの整理を通じて、日本の駅トイレに特有な「改札内外」「構内での位置」「案内方法」などが既存タグでは十分に表現できない課題が明確になり、新たなタグ提案の必要性が示された。
